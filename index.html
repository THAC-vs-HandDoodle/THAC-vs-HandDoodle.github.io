Lesson 01 距离与范数

距离和距离空间

定义

非空集合\(X\)，对\(X\)中任意两元素\(x,y\)，按某一法则对应唯一的实数\(d(x,y)\)，满足:
1.\(d(x,y)\geq0\)（当仅\(x=y\)时取”\(=\)“）
2.\(d(x,y)=d(y,x)\)
3.\(d(x,y)\leq d(x,z)+d(y,z)\)
则称\(d(x,y)\)为\(x\)与\(y\)之间的距离，并称\(X\)是以\(d\)为距离的距离空间，记作\((X,d)\)。

例

\(d(x,y)=\begin{cases}1, & x \neq y \\0, & x = y\end{cases}\)是一个离散距离空间\((X,d)\)。

\(L1\)距离

对\(X=\mathbb{R}^{n},x=(x_i),y=(y_i)\)，（也就是\(n\)维向量），有:(下两个同理) \(d_1(x,y)=\sum_{i=1}^{n} |x_i-y_i|\)（沿\(x,y\)等坐标轴走的那种直角折线）

\(L2\)距离

\(d_2(x,y)=\left\{\sum_{i=1}^{n} (x_i-y_i)^{2}\right\}^{1/2}\)（两点之间的直接直线距离，\(n\)维推广）

\(L\infty\)距离

\(d_\infty(x,y)=\max_{i} |x_i-y_i|\)（沿\(x,y\)等坐标轴走的最长单条折线）

\(l^p\) 空间

对 \(1 \le p < \infty\)，记\(l^p = \left\{ x : x = (x_1, x_2, \dots, x_i, \dots)^T,\ \sum_{i=1}^\infty |x_i|^p < \infty \right\}\)（无穷数列，每项p次方和为有限数） 对\(x = (x_1, x_2, \dots, x_i, \dots)^T,\quad y = (y_1, y_2, \dots, y_i, \dots)^T \in l^p,\)
\(d_p(x, y) = \left\{ \sum_{i=1}^\infty |x_i - y_i|^p \right\}^{1/p}.\) 则 \((l^p, d_p)\) 是距离空间。

\(l^\infty\) 空间

记\(l^\infty = \{x : x = (x_1, x_2, \dots)^T, \sup_i |x_i| < \infty\},\)（sup：上确界）（每一项都是有限数，不会随数列无限而无上界） 对 \(x = (x_1, x_2, \dots, x_i, \dots)^T\)，\(y = (y_1, y_2, \dots, y_i, \dots)^T \in l^\infty\)，定义\(d_\infty(x, y) := \sup_i |x_i - y_i|,\) 则 \((l^\infty, d_\infty)\) 是距离空间.

极限与收敛

设 \(\{x_n\}_{n=1}^\infty\) 是距离空间 \((X,d)\) 中点列，\(x_0\) 是 \(X\) 中确定的点。若对任何给定的正数 \(\varepsilon\)，总存在自然数 \(N\)，当 \(n>N\) 时成立\(d(x_n, x_0) < \varepsilon,\)则称点列 \(\{x_n\}_{n=1}^\infty\) 收敛于 \(x_0\)，或者说 \(x_0\) 是 \(\{x_n\}_{n=1}^\infty\) 的极限，记作 \[\lim_{n \to \infty} x_n = x_0 或者 x_n \to x_0\ (n \to \infty)\] （简单可过）

Cauchy列与完备

定义

设 \(\{x_n\}_{n=1}^\infty\) 是距离空间 \((X,d)\) 中点列 （当成数列），若对任何 \(\varepsilon>0\)，都存在 \(N \in \mathbb{N}\)，使得当 \(n,m > N\) 时有 \(d(x_m, x_n) < \varepsilon,\)则称 \(\{x_n\}_{n=1}^\infty\) 为 Cauchy 列。(两个点之间在很后面的时候逐渐挤到一起，但是不需要知道收敛于的特定值) 如果 \(X\) 中任何 Cauchy 列都在 \(X\) 中收敛，则称 \(X\) 是完备的。

例

在有理数空间\(\mathbb{Q}\)里，数列 \(x_n=(1+\frac{1}{n})^n\)是 Cauchy 列，但它的极限\(e\)不在\(\mathbb{Q}\)里，所以在\(\mathbb{Q}\)中这个 Cauchy 列不收敛。 \(\mathbb{Q}\)是不完备的（上面那个就是一个不收敛的Cauchy列例子），\(\mathbb{R}\)是完备的。

范数和赋范线性空间

直接定义

设 \(X\) 是复数域 \(\mathbb{C}\) 上线性空间，\(0\) 为 \(X\) 的零元素，若对 \(X\) 中每一个元素 \(x\)，按照一个法则 （输入元素输出实数）对应一个实数 \(\|x\|\) 满足：（注意是实数！）

  1. \(\|x\| \ge 0\) 且 \(\|x\| = 0\) 当且仅当 \(x = 0\)；
  2. \(\|x + y\| \le \|x\| + \|y\|\)（\(x,y \in X\)）；（三角不等式，毕竟x+y类似矢量加）
  3. \(\|\alpha x\| = |\alpha|\|x\|\)（\(\alpha \in \mathbb{C}, x \in X\)），

则称 \(\|x\|\) 为 \(x\) 的范数，\(X\) 称为以 \(\|\cdot\|\) 为范数的赋范线性空间。

碎碎念

范数相当于给线性空间定义了长度/大小这个概念。 你最好还记得线性空间不是专指矩阵空间、向量空间之类的概念。它是一个极为抽象的概念，满足一定条件 （希望你没忘记你的线性代数） 就可以被叫做线性空间。 范数的值是实数。一个线性空间有了范数，就可以试着类比着被当做经典三维空间来看了。

Banach空间

对于赋范线性空间，通过公式 \(d(x, y) = \|x - y\|\) 可以定义元素之间的距离，容易验证 \(d(x,y)\) 满足距离的三个条件，因而 \(X\) 是一个距离空间。（将范数视为距离空间的距离的距离空间） 完备的赋范线性空间称为 Banach 空间。（它是泛函分析的核心研究对象）

例

\(\mathbb{C}^n\) 与 \(l^p\)（\(p>1\)）分别在以下范数下是赋范线性空间，而且是 Banach 空间： \[ \|x\| = \left( \sum_{i=1}^n |x_i|^2 \right)^{\frac{1}{2}},\quad x = (x_1, x_2, \dots, x_n) \in \mathbb{C}^n, \] （含义其实就是直线距离的求法，每项平方加起来开根） \[ \|x\| = \left( \sum_{i=1}^\infty |x_i|^p \right)^{\frac{1}{p}},\quad x = (x_1, x_2, \dots, x_n, \dots) \in l^p. \] \(\mathbb{C}^n\)其实就是复数域的n维线性空间。\(l^p\)在上面已经提到过，范数也是上面的距离。

范数的强于和等价

定义

设 \(X\) 是一线性空间，\(\|\cdot\|_1\) 和 \(\|\cdot\|_2\) 是 \(X\) 上两个范数， 如果\(\lim_{n \to \infty} \|x_n\|_1 = 0 \implies \lim_{n \to \infty} \|x_n\|_2 = 0,\)则称 \(\|\cdot\|_1\) 强于 \(\|\cdot\|_2\)； 如果\(\lim_{n \to \infty} \|x_n\|_1 = 0 \iff \lim_{n \to \infty} \|x_n\|_2 = 0,\)则称 \(\|\cdot\|_1\) 等价于 \(\|\cdot\|_2\)。

其他判定

  • 若存在常数 $ 0 < m M < $，使得对所有 $ x X \(，有\)m|x|_2≤|x|_1≤M|x|_2$，（不等式判别） 则两个范数等价。
  • 对于 一般的有限维线性空间 \(X\) ，\(\|\cdot\|_1\) 与 \(\|\cdot\|_2\) 是 \(X\) 上定义的两个范数，则 \(\|\cdot\|_1\) 与 \(\|\cdot\|_2\) 等价。 （相应地，\(l^p\)空间就不符合这一条。）

赋范线性空间的性质

  • 设 \(X\) 是赋范线性空间，\(\{x_n\} \subset X,\ x \in X\)，若 \(\lim_{n \to \infty} x_n = x\)，则 \(\{\|x_n\|\}\) 是有界数列。（收敛点列的范数数列有界）

  • 设 \(X\) 是定义在 \(\mathbb{C}\) 上的赋范线性空间，\(\{x_n\},\{y_n\}\) 为 \(X\) 中点列，\(\{\alpha_n\} \subset \mathbb{C},\ x,y \in X,\ \alpha \in \mathbb{C}\) 满足\(\lim_{n \to \infty} x_n = x,\quad \lim_{n \to \infty} y_n = y,\quad \lim_{n \to \infty} \alpha_n = \alpha,\)则

  1. \(\lim_{n \to \infty} (x_n + y_n) = x + y\)，
  2. \(\lim_{n \to \infty} \alpha_n x_n = \alpha x\)。 （人话就是加法、数乘对极限是连续的。）

向量范数

定义

对于 \(F^n\)（实或复欧几里得空间 （就是一般几何上的那种） ）中的向量 \(x\) 与 \(y\)， 既可以用 \(x-y\) 的 欧几里得(Euclid) 长度 （就是一般的直线长度） 来描述 \(x\) 与 \(y\) 之间的距离，
也可以用 \(x-y\) 的 范数 来描述它们之间的距离。

例

设 \(x = (\xi_1, \xi_2, \dots, \xi_n)^T \in \mathbb{C}^n\)，规定如下： （其实有证明，但是实在不想看了。真想看的话写在这里也不如自己去找ppt看）

1-范数

\(\|x\|_1 = \sum_{k=1}^n |\xi_k|\) (每个分量绝对值之和，折线样子的那个曼哈顿距离)

2-范数

\(\|x\|_2 = \sqrt{\sum_{k=1}^n |\xi_k|^2} = \sqrt{x^H x}\) （经典几何直线距离，\(x^H\)的H上标表示共轭转置，也就是矩阵/向量转置后对复元素取共轭。这里使用\(x^{H}x\)是列出用向量的模表示2-范数的写法）

\(\infty\)-范数

\(\|x\|_\infty = \max_k |\xi_k|\) （最大的那一个分量的绝对值）

p-范数

\(\|x\|_p = \left(\sum_{k=1}^n |\xi_k|^p\right)^{1/p}\) (\(1 \le p < \infty\)) 注：\(\lim_{p \to \infty} \|x\|_p = \|x\|_\infty\) （可以认为是广义上的平均长度，但我还没想通。）

矩阵范数与酉矩阵

矩阵范数定义

如果 \(\mathbb{C}^{n \times n}\) 上的一个实函数\(\|\cdot\|: \mathbb{C}^{n \times n} \to \mathbb{R}\)满足以下条件：

  1. \(\|A\| \ge 0\)，且 \(\|A\| = 0\) 当且仅当 \(A = 0\)（非负性）；
  2. 对 \(\lambda \in \mathbb{C}\)，\(\|\lambda A\| = |\lambda| \|A\|\)（齐次性）；
  3. \(\|A + B\| \le \|A\| + \|B\|\)（三角不等式）；
  4. \(\|AB\| \le \|A\| \|B\|\)（相容性 (矩阵范数相对于向量范数独占)），

（矩阵相乘本来就可以理解为加以变换，相容性可以理解为复合变换的 “放大倍数” 不超过两个变换各自 “放大倍数” 的乘积，本质我认为还是类三角不等式的思想，复合不如分别简单的和/积）

则称 \(\|\cdot\|\) 为一个矩阵范数，而 \(\|A\|\) 为 \(\mathbb{C}^{n \times n}\) 上矩阵 \(A\) 的范数。
