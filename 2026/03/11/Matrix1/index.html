Lesson 01 距离与范数

距离和距离空间

定义

非空集合\(X\)，对\(X\)中任意两元素\(x,y\)，按某一法则对应唯一的实数\(d(x,y)\)，满足:

1.\(d(x,y)\geq0\)（当仅\(x=y\)时取”\(=\)“）

2.\(d(x,y)=d(y,x)\)

3.\(d(x,y)\leq d(x,z)+d(y,z)\)

则称\(d(x,y)\)为\(x\)与\(y\)之间的距离，并称\(X\)是以\(d\)为距离的距离空间，记作\((X,d)\)。

例

\(d(x,y)=\begin{cases}1, & x \neq y \\0, & x = y\end{cases}\)是一个离散距离空间\((X,d)\)。

\(L1\)距离

对\(X=\mathbb{R}^{n},x=(x_i),y=(y_i)\)，（也就是\(n\)维向量），有:（下两个同理）

\(d_1(x,y)=\sum_{i=1}^{n} |x_i-y_i|\)（沿\(x,y\)等坐标轴走的那种直角折线）

\(L2\)距离

\(d_2(x,y)=\left\{\sum_{i=1}^{n} (x_i-y_i)^{2}\right\}^{1/2}\)（两点之间的直接直线距离，\(n\)维推广）

\(L\infty\)距离

\(d_\infty(x,y)=\max_{i} |x_i-y_i|\)（沿\(x,y\)等坐标轴走的最长单条折线）

\(l^p\) 空间

对 \(1 \le p < \infty\)，记\(l^p = \left\{ x : x = (x_1, x_2, \dots, x_i, \dots)^T,\ \sum_{i=1}^\infty |x_i|^p < \infty \right\}\)（无穷数列，每项p次方和为有限数）

对\(x = (x_1, x_2, \dots, x_i, \dots)^T,\quad y = (y_1, y_2, \dots, y_i, \dots)^T \in l^p,d_p(x, y) = \left\{ \sum_{i=1}^\infty |x_i - y_i|^p \right\}^{1/p}.\)

则 \((l^p, d_p)\) 是距离空间。

\(l^\infty\) 空间

记\(l^\infty = \{x : x = (x_1, x_2, \dots)^T, \sup_i |x_i| < \infty\},\)（sup：上确界）（每一项都是有限数，不会随数列无限而无上界）

对 \(x = (x_1, x_2, \dots, x_i, \dots)^T\)，\(y = (y_1, y_2, \dots, y_i, \dots)^T \in l^\infty\)，定义\(d_\infty(x, y) := \sup_i |x_i - y_i|,\)

则 \((l^\infty, d_\infty)\) 是距离空间.

极限与收敛

设 \(\{x_n\}_{n=1}^\infty\) 是距离空间 \((X,d)\) 中点列，\(x_0\) 是 \(X\) 中确定的点。若对任何给定的正数 \(\varepsilon\)，总存在自然数 \(N\)，当 \(n>N\) 时成立\(d(x_n, x_0) < \varepsilon,\)则称点列 \(\{x_n\}_{n=1}^\infty\) 收敛于 \(x_0\)，或者说 \(x_0\) 是 \(\{x_n\}_{n=1}^\infty\) 的极限，记作

\[\lim_{n \to \infty} x_n = x_0 或者 x_n \to x_0\ (n \to \infty)\]

（简单可过）

Cauchy列与完备

定义

设 \(\{x_n\}_{n=1}^\infty\) 是距离空间 \((X,d)\) 中点列 （当成数列），若对任何 \(\varepsilon>0\)，都存在 \(N \in \mathbb{N}\)，使得当 \(n,m > N\) 时有 \(d(x_m, x_n) < \varepsilon,\)则称 \(\{x_n\}_{n=1}^\infty\) 为 Cauchy 列。(两个点之间在很后面的时候逐渐挤到一起，但是不需要知道收敛于的特定值)

如果 \(X\) 中任何 Cauchy 列都在 \(X\) 中收敛，则称 \(X\) 是完备的。

例

在有理数空间\(\mathbb{Q}\)里，数列 \(x_n=(1+\frac{1}{n})^n\)是 Cauchy 列，但它的极限\(e\)不在\(\mathbb{Q}\)里，所以在\(\mathbb{Q}\)中这个 Cauchy 列不收敛。

\(\mathbb{Q}\)是不完备的（上面那个就是一个不收敛的Cauchy列例子），\(\mathbb{R}\)是完备的。

范数和赋范线性空间

直接定义

设 \(X\) 是复数域 \(\mathbb{C}\) 上线性空间，\(0\) 为 \(X\) 的零元素，若对 \(X\) 中每一个元素 \(x\)，按照一个法则 （输入元素输出实数）对应一个实数 \(\|x\|\) 满足：（注意是实数！）

  • \(\|x\| \ge 0\) 且 \(\|x\| = 0\) 当且仅当 \(x = 0\)；

  • \(\|x + y\| \le \|x\| + \|y\|\)（\(x,y \in X\)）；（三角不等式，毕竟x+y类似矢量加）

  • \(\|\alpha x\| = |\alpha|\|x\|\)（\(\alpha \in \mathbb{C}, x \in X\)），

则称 \(\|x\|\) 为 \(x\) 的范数，\(X\) 称为以 \(\|\cdot\|\) 为范数的赋范线性空间。

碎碎念

范数相当于给线性空间定义了长度/大小这个概念。

你最好还记得线性空间不是专指矩阵空间、向量空间之类的概念。它是一个极为抽象的概念，满足一定条件 （希望你没忘记你的线性代数） 就可以被叫做线性空间。

范数的值是实数。一个线性空间有了范数，就可以试着类比着被当做经典三维空间来看了。

Banach空间

对于赋范线性空间，通过公式 \(d(x, y) = \|x - y\|\) 可以定义元素之间的距离，容易验证 \(d(x,y)\) 满足距离的三个条件，因而 \(X\) 是一个距离空间。（将范数视为距离空间的距离的距离空间）

完备的赋范线性空间称为 Banach 空间。（它是泛函分析的核心研究对象）

例

\(\mathbb{C}^n\) 与 \(l^p\)（\(p>1\)）分别在以下范数下是赋范线性空间，而且是 Banach 空间：

\[ \|x\| = \left( \sum_{i=1}^n |x_i|^2 \right)^{\frac{1}{2}},\quad x = (x_1, x_2, \dots, x_n) \in \mathbb{C}^n, \]

（含义其实就是直线距离的求法，每项平方加起来开根）

\[ \|x\| = \left( \sum_{i=1}^\infty |x_i|^p \right)^{\frac{1}{p}},\quad x = (x_1, x_2, \dots, x_n, \dots) \in l^p. \]

（\(\mathbb{C}^n\)其实就是复数域的n维线性空间。\(l^p\)在上面已经提到过，范数也是上面的距离。）

范数的强于和等价

定义

设 \(X\) 是一线性空间，\(\|\cdot\|_1\) 和 \(\|\cdot\|_2\) 是 \(X\) 上两个范数，

如果\(\lim_{n \to \infty} \|x_n\|_1 = 0 \implies \lim_{n \to \infty} \|x_n\|_2 = 0,\)则称 \(\|\cdot\|_1\) 强于 \(\|\cdot\|_2\)；

如果\(\lim_{n \to \infty} \|x_n\|_1 = 0 \iff \lim_{n \to \infty} \|x_n\|_2 = 0,\)则称 \(\|\cdot\|_1\) 等价于 \(\|\cdot\|_2\)。

其他判定

  • 若存在常数 $ 0 < m M < $，使得对所有 $ x X \(，有\)m|x|_2≤|x|_1≤M|x|_2$，（不等式判别） 则两个范数等价。

  • 对于 一般的有限维线性空间 \(X\) ，\(\|\cdot\|_1\) 与 \(\|\cdot\|_2\) 是 \(X\) 上定义的两个范数，则 \(\|\cdot\|_1\) 与 \(\|\cdot\|_2\) 等价。

（相应地，\(l^p\)空间就不符合这一条。）

赋范线性空间的性质

  • 设 \(X\) 是赋范线性空间，\(\{x_n\} \subset X,\ x \in X\)，若 \(\lim_{n \to \infty} x_n = x\)，则 \(\{\|x_n\|\}\) 是有界数列。（收敛点列的范数数列有界）

  • 设 \(X\) 是定义在 \(\mathbb{C}\) 上的赋范线性空间，\(\{x_n\},\{y_n\}\) 为 \(X\) 中点列，\(\{\alpha_n\} \subset \mathbb{C},\ x,y \in X,\ \alpha \in \mathbb{C}\) 满足\(\lim_{n \to \infty} x_n = x,\quad \lim_{n \to \infty} y_n = y,\quad \lim_{n \to \infty} \alpha_n = \alpha,\)则

    • \(\lim_{n \to \infty} (x_n + y_n) = x + y\)，

    • \(\lim_{n \to \infty} \alpha_n x_n = \alpha x\)。 （人话就是加法、数乘对极限是连续的。）

向量范数

定义

对于 \(F^n\)（实或复欧几里得空间 （就是一般几何上的那种） ）中的向量 \(x\) 与 \(y\)，

既可以用 \(x-y\) 的 欧几里得(Euclid) 长度 （就是一般的直线长度） 来描述 \(x\) 与 \(y\) 之间的距离，

也可以用 \(x-y\) 的 范数 来描述它们之间的距离。

例

设 \(x = (\xi_1, \xi_2, \dots, \xi_n)^T \in \mathbb{C}^n\)，规定如下：

（其实有证明，但是实在不想看了。真想看的话写在这里也不如自己去找ppt看）

1-范数

\(\|x\|_1 = \sum_{k=1}^n |\xi_k|\) (每个分量绝对值之和，折线样子的那个曼哈顿距离)

2-范数

\(\|x\|_2 = \sqrt{\sum_{k=1}^n |\xi_k|^2} = \sqrt{x^H x}\) （经典几何直线距离，\(x^H\)的H上标表示共轭转置，也就是矩阵/向量转置后对复元素取共轭。这里使用\(x^{H}x\)是列出用向量的模表示2-范数的写法）

\(\infty\)-范数

\(\|x\|_\infty = \max_k |\xi_k|\) （最大的那一个分量的绝对值）

p-范数

\(\|x\|_p = \left(\sum_{k=1}^n |\xi_k|^p\right)^{1/p}\) (\(1 \le p < \infty\))

注：\(\lim_{p \to \infty} \|x\|_p = \|x\|_\infty\)

（可以认为是广义上的平均长度，但我还没想通。）

矩阵范数与酉矩阵

矩阵范数定义

如果 \(\mathbb{C}^{n \times n}\) 上的一个实函数\(\|\cdot\|: \mathbb{C}^{n \times n} \to \mathbb{R}\)满足以下条件：

  • \(\|A\| \ge 0\)，且 \(\|A\| = 0\) 当且仅当 \(A = 0\)（非负性）；

  • 对 \(\lambda \in \mathbb{C}\)，\(\|\lambda A\| = |\lambda| \|A\|\)（齐次性）；

  • \(\|A + B\| \le \|A\| + \|B\|\)（三角不等式）；

  • \(\|AB\| \le \|A\| \|B\|\)（相容性 (矩阵范数相对于向量范数独占)），

（矩阵相乘本来就可以理解为加以变换，相容性可以理解为复合变换的 “放大倍数” 不超过两个变换各自 “放大倍数” 的乘积，本质我认为还是类三角不等式的思想，复合不如分别简单的和/积）

则称 \(\|\cdot\|\) 为一个矩阵范数，而 \(\|A\|\) 为 \(\mathbb{C}^{n \times n}\) 上矩阵 \(A\) 的范数。

例

设 \(A = (a_{ij})_{n \times n} \in \mathbb{C}^{n \times n}\)，规定:(n*n的复矩阵)

\(m_1\)范数

\(\|A\|_{m_1} = \sum_{i=1}^n \sum_{j=1}^n |a_{ij}|\)

（拉平后取向量1-范数，也就是矩阵里所有元素的绝对值和）

\(m_\infty\)范数

\(\|A\|_{m_\infty} = n \max_{i,j} |a_{ij}|\)

（拉平后取向量\(\infty\)-范数，也就是矩阵里绝对值最大的元素后，乘n来满足相容性）

\(F\)范数（Frobenius 范数）

\(\|A\|_F = \sqrt{\sum_{i=1}^n \sum_{j=1}^n |a_{ij}|^2} = \sqrt{\mathrm{tr}(A^H A)}\)

（拉平后取向量2-范数，也就是对矩阵每个元素的平方求和再开根，tr表示迹，也就是对角线元素和，此处每个对角线上的元素都是该元素所在列的所有元素的平方的和）

酉矩阵定义

设 \(A \in \mathbb{C}^{n \times n}\)，若 \(A\) 满足\(A^H A = I\)，则称 \(A\) 为酉矩阵。

(\(A^H\)介绍过是共轭转置（Hermitian 转置），而在实矩阵时与一般转置\(A^T\)相同，故实空间的酉矩阵就是正交矩阵的概念)

酉矩阵性质

设 \(A,B \in \mathbb{C}^{n \times n}\)。

  1. 若 \(A\) 是酉矩阵，则 \(A^{-1}, A^H, A^T, \overline{A}, A^k\ (k=1,2,\dots)\) 均为酉矩阵；（逆、共轭转置、转置、共轭、幂次，仍然是酉矩阵）

  2. 若 \(A,B\) 是酉矩阵，则 \(AB\) 也是酉矩阵；（乘法封闭）

  3. 若 \(A\) 是酉矩阵，则 \(|\det A| = 1\)；（由定义取模可得）

  4. \(A\) 是酉矩阵的充要条件是 \(A\) 的 \(n\) 个列向量是标准正交向量组；

  5. \(A\) 是酉矩阵的充要条件是 \(A\) 的 \(n\) 个行向量是标准正交向量组；

  6. \(A\) 是酉矩阵的充要条件是对任意 \(\alpha,\beta \in \mathbb{C}^n\)，有\((A\alpha, A\beta) = (\alpha, \beta);\)

（酉变换是等距变换： \((A\alpha,A\beta)=(A\alpha)^{H}(A\beta)=\alpha^{H}A^{H}A\beta=\alpha^{H}\beta=(\alpha,\beta)\) 。）

（特别地，令 \(\alpha=\beta\) 得 \(\|A\alpha\|_2=\|\alpha\|_2\) ，即酉变换保持向量的 2 - 范数不变。）

  1. 若 \(A\) 是酉矩阵，\(\lambda\) 为 \(A\) 的特征值，则 \(|\lambda| = 1\)。（令 \(\alpha = \beta\) 可得）

酉不变性

对酉矩阵 \(U, V\)，有\(\|UA\|_F = \|AV\|_F = \|UAV\|_F = \|A\|_F\)

（对这条，理解成类比可逆矩阵那样左乘右乘都不改变矩阵的秩的那种形状就可以了，这里是左乘或右乘酉矩阵都不改变矩阵的F范数）

矩阵范数的相似不变性定理

设 \(\|\cdot\|\) 是 \(\mathbb{C}^{n \times n}\) 上一个矩阵范数，\(G \in \mathbb{C}^{n \times n}\) 是一个可逆矩阵，则\(\|A\|_G = \|G^{-1} A G\|, A \in \mathbb{C}^{n \times n}\)是矩阵范数。

（可以理解成相似变换不会破坏范数的公理结构，只是对原范数做了一个 “坐标变换” 后的版本。）

算子范数

定义

设 \(\|\cdot\|\) 是 \(\mathbb{C}^n\) 上的向量范数，定义 \(\mathbb{C}^{n \times n}\) 上的函数 \(\|\cdot\|_m\) 是 \(\mathbb{C}^{n \times n}\) 上的矩阵范数： \[ \|A\|_m = \max_{\|x\|=1} \|Ax\|,\quad A \in \mathbb{C}^{n \times n} \]

（||x||是某个向量范数，根据情况看。max||Ax||可以理解为被A作用后拉伸得最长的单位向量的范数。）

称该矩阵范数为 算子范数（或由向量范数 \(\|\cdot\|\) 诱导的矩阵范数）。

定理：

  1. 相容性：\(\|Ax\| \le \|A\|_m \|x\|\) 对所有 \(A \in \mathbb{C}^{n \times n}\) 和 \(x \in \mathbb{C}^n\) 成立；

  2. 单位范数：对单位矩阵 \(I\)，\(\|I\|_m = 1\)。（因为单位矩阵怎么作用于单位向量，其范数都不变）

常用算子范数例

极大列和范数

\({\|A\|_1 = \max_{j} \sum_{i=1}^n |a_{ij}|}\)

  • 对矩阵的每一列，计算该列所有元素绝对值的和，然后取这些列和中的最大值。

  • 对应向量 1-范数诱导的算子范数。

谱范数

\({\|A\|_2 = \sqrt{\lambda_1}}\) （其中 \(\lambda_1\) 为 \(A^H A\) 的最大特征值）

  • 等于矩阵 \(A\) 的最大奇异值（即 \(A^H A\) 最大特征值的平方根）。

  • 对应向量 2-范数诱导的算子范数，具有酉不变性 （见F范数）。

极大行和范数

\({\|A\|_\infty = \max_{i} \sum_{j=1}^n |a_{ij}|}\)，

  • 对矩阵的每一行，计算该行所有元素绝对值的和，然后取这些行和中的最大值。

  • 对应向量 \(\infty\)-范数诱导的算子范数。

Hermite矩阵和正规矩阵

定义

设 \(A \in \mathbb{C}^{n \times n}\)，则：

  • Hermite 矩阵：若 \(A^H = A\)，则称 \(A\) 为 Hermite 矩阵。

  • 反 Hermite 矩阵：若 \(A^H = -A\)，则称 \(A\) 为 反 Hermite 矩阵。

  • 正规矩阵：若 \(A^H A = A A^H\)，则称 \(A\) 为 正规矩阵。

性质

  • Hermite 矩阵：主对角线元素全为实数。

  • 反 Hermite 矩阵：主对角线元素全为零或纯虚数。

  • 实对称矩阵（\(A^T = A\)）是 Hermite 矩阵的特例。

  • 实反对称矩阵（\(A^T = -A\)）是反 Hermite 矩阵的特例。（记的时候从这俩入手就好）

正规矩阵的包含关系

以下矩阵都是正规矩阵：

  • 对角矩阵

  • 实对称矩阵、实反对称矩阵 \((A^{T}=-A)\)

  • Hermite 矩阵、反 Hermite 矩阵

  • 正交矩阵、酉矩阵

谱范数相关

谱范数的性质

定义回顾：\({\|A\|_2 = \sqrt{\lambda_1}}\) （其中 \(\lambda_1\) 为 \(A^H A\) 的最大特征值）

设 \(U, V\) 为酉矩阵。

  • \(\|UA\|_2 = \|AV\|_2 = \|UAV\|_2 = \|A\|_2\); （上面提到过的酉不变性）

  • 若 \(A\) 是正规矩阵 （务必注意前提条件！），且 \(\lambda_1, \lambda_2, \dots, \lambda_n\) 是 \(A\) 的 \(n\) 个特征值，则\(\|A\|_2 = \max_{k} |\lambda_k|.\)

另外还有：

\[ \begin{aligned} \|A^H\|_{m_1} &= \|A\|_{m_1}, \quad \|A^H\|_F = \|A\|_F, \\ \|A^H\|_{m_\infty} &= \|A\|_{m_\infty}, \quad \|A^H\|_\infty = \|A\|_1, \\ \|A^H\|_1 &= \|A\|_\infty, \quad \|A^H\|_2 = \|A\|_2. \end{aligned} \]

（共轭转置矩阵和原矩阵的 \(m_1\) 范数、 \(m_\infty\) 范数、F范数、极大行和范数、极大列和范数、谱范数都相等。）

例题展示

设 \(U\) 是酉矩阵，\(A = \begin{pmatrix} -1 & i & 0 \\ -i & 0 & -i \\ 0 & i & -1 \end{pmatrix}\)，试计算 $_{|x|_1=4} |Ax|1 $ 及 $ {|Ux|_2=3} |Ax|_2.$

解：

首先设 \(x = 4y\)，则 \[ \max_{\|x\|_1=4} \|Ax\|_1 = \max_{\|y\|_1=1} 4\|Ay\|_1 = 4\|A\|_1 = 8. \]

其次设 \(x = 3U^H y\)，则 \[ \max_{\|Ux\|_2=3} \|Ax\|_2 = \max_{\|y\|_2=1} 3\|AU^H y\|_2 = 3\|AU^H\|_2 = 3\|A\|_2. \]

而 \(A\) 是 Hermite 矩阵，其特征值为 \(\lambda_1 = -2, \lambda_2 = -1, \lambda_3 = 1\)。所以 \[ \max_{\|Ux\|_2=3} \|Ax\|_2 = 3\|A\|_2 = 3|\lambda_1| = 6. \]
